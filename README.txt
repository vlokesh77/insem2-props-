CRICKET SCOREBOARD - REACT PROJECT

PROJECT FEATURES
- App.jsx stores the score using useState.
- ScoreBoard.jsx receives and displays score through props.
- Controls.jsx receives addRun and resetScore functions through props.
- Buttons add 1, 2, 3, 4, or 6 runs.
- Reset Score sets the score back to zero.

HOW TO RUN
1. Extract this ZIP file.
2. Open the extracted cricket_scoreboard_react folder in VS Code.
3. Open Terminal > New Terminal.
4. Run: npm install
5. Run: npm run dev
6. Open the localhost URL shown in the terminal (usually http://localhost:5173).
